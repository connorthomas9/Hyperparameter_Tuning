## Overview
In this project, we will be using different hyperparameter tuning methods to classify the different types of raisins. This dataset has been posted on `Kaggle` by `Murat Koklu`, a researcher who has studied different raisin grain types using machine learning methods.

The primary analysis takes place in the `ht_notebook.ipynb` Jupyter Notebook file

The dataset used for this project is the `Raisin_Dataset.csv` file

This project comes by way of `Codecademy.com` and has been recreated from scratch in order to demonstrate knowledge of applied usage of hyperparameter tuning methods such as the gird search method used to tune a decision tree classifier as well as the random search method to tune a logistic regression classifier
